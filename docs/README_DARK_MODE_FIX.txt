GATASIA - Universal Dark Mode Fix

Perbaikan CSS untuk menyesuaikan latar putih dan ikon di semua halaman saat Dark Mode aktif.

Cara menjalankan: dari folder gatasia_merge_build, jalankan: node backend/server.js lalu buka http://localhost:3000.
Setelah membuka browser, lakukan hard refresh (Ctrl+Shift+R). Pastikan folder baru hasil ekstraksi yang dijalankan.
