GATASIA — Perbaikan kontras dark mode lintas halaman

Perbaikan ini menambahkan aturan CSS dark mode yang lebih kuat untuk halaman Beranda, Jelajah Peta, Misi Harian, Papan Peringkat, dan Profil. Kartu yang sebelumnya tetap putih/ice-blue diubah menjadi panel gelap; teks pucat pada kartu tersebut dibuat terang; teks sekunder dibuat abu-abu terang; label peta tetap terbaca.

Cara pakai:
1. Ekstrak ZIP ke folder baru.
2. Jalankan website sesuai instruksi backend pada README_BACKEND.txt (jika Node.js/backend digunakan).
3. Buka website dan aktifkan tombol dark mode pada navbar.
4. Jika browser masih menampilkan CSS lama, tekan Ctrl+Shift+R untuk hard refresh.

Catatan: warna ilustrasi peta sengaja tidak dibalik/digelapkan agar bentuk wilayah tetap terlihat.
