GATASIA — Website demo dengan perbaikan peta dan posisi pin provinsi

CARA MENJALANKAN:
1. Ekstrak ZIP.
2. Buka folder gatasia_merge_build.
3. Klik dua kali index.html untuk membuka website.
4. Buka menu Jelajahi Peta untuk melihat peta yang diperbarui.

PERUBAHAN V21:
- Posisi pin provinsi ditata ulang agar mengikuti lokasi geografis pulau pada siluet peta.
- Seluruh 38 provinsi memakai posisi dari province_data.js.
- Label pin diringkas agar lebih mudah dibaca dan tidak terlalu memenuhi peta.
- Tombol zoom dan interaksi pilihan provinsi tetap tersedia.

CATATAN:
Peta ini masih berupa ilustrasi SVG, bukan peta batas administrasi resmi. Posisi pin sudah ditata ulang mengikuti siluet pulau, tetapi tidak dapat menjamin akurasi koordinat administratif sampai tingkat kabupaten/provinsi. Untuk presisi kartografis, gunakan geodata resmi/GeoJSON dan render marker dari koordinat lintang-bujur.
